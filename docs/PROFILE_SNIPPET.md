### 🧠 [see-the-ai-think](https://github.com/bettyguo/see-the-ai-think)

> Watch an LLM think. Interactive interpretability tool — load a small open model, type a prompt, see the sparse-autoencoder features light up across layers and tokens. **Runs on your laptop, no GPU.**

![demo](https://github.com/bettyguo/see-the-ai-think/raw/main/assets/demo.gif)

Built around [TransformerLens](https://github.com/TransformerLensOrg/TransformerLens) + [SAELens](https://github.com/decoderesearch/SAELens) + [Neuronpedia](https://neuronpedia.org) auto-interp labels. The honesty rules are load-bearing — every interpretive claim carries a `MEASURED`/`SOURCED`/`AUTO-LABEL` tier badge.

[![stars](https://img.shields.io/github/stars/bettyguo/see-the-ai-think?style=social)](https://github.com/bettyguo/see-the-ai-think) · [live demo](https://huggingface.co/spaces/bettyguo/see-the-ai-think) · MIT
